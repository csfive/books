# Books

计算机相关书籍，侵删。

## 下载

本仓库的 PDF 使用 Git LFS 存储，请先安装 Git LFS。

```sh
git lfs install
git clone https://github.com/csfive/books.git
cd books
```

如果 clone 后看到的 PDF 不是正常文件，可以手动拉取 LFS 文件：

```sh
git lfs pull
```
